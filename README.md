# ScreenCaptureOCR Translator —— 屏幕截图 AI 翻译工具

Windows 桌面常驻工具：按下全局快捷键 → 拖拽矩形选区 → 千问视觉模型一次调用完成「英文识别 + 中文翻译 + 文本坐标」→ 译文覆盖回屏幕原文位置 → 按 ESC 退出。

> **v1.1**：无本地 OCR 依赖，纯千问视觉模型一条龙服务，打包体积仅 46MB。

## 安装

### 方式一：下载打包好的 exe（推荐）

1. 解压 `ScreenCaptureTranslator.zip` 到任意目录
2. 双击 `ScreenCaptureTranslator.exe` 启动
3. 首次启动自动显示主窗口，填入 API Key，点击保存

### 方式二：从源码运行

**要求**：Python 3.8+（64 位）

```bash
cd translate
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 首次使用（必须配置 API Key）

本工具需要用户自行提供**阿里云百炼（DashScope）**的 API Key：

1. 访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 注册/登录阿里云账号
3. 在「模型广场」开通 `qwen-vl-plus`（或其他视觉模型）
4. 在「API Key 管理」创建 API Key
5. 在主窗口设置区填入 API Key → 点击「💾 保存设置」

### 可用模型

| 模型 | 说明 |
|---|---|
| `qwen-vl-plus`（默认） | 均衡性价比，日常推荐 |
| `qwen-vl-max` | 最强精度，复杂排版 |
| `qwen2.5-vl-72b-instruct` | 开源旗舰 |
| `qwen3-vl-plus` | 最新一代 |

> 模型名以阿里云百炼控制台实际可用为准，主窗口下拉框支持自定义输入。

## 使用流程

1. 启动 → 主窗口出现 + 托盘图标
2. 填入 API Key → 保存设置
3. 按 `Ctrl+Alt+T`（或自定义快捷键）→ 屏幕变暗
4. 拖拽矩形框选要翻译的英文区域 → 松开鼠标
5. 等待 3-8 秒 → 中文译文覆盖在原文位置
6. 阅读完毕按 `ESC` 退出覆盖层
7. 翻译记录自动出现在主窗口日志中

> 也可右键托盘图标 →「截图翻译」触发（不依赖热键）。

## 常见问题

**Q: 热键无效？**
- 确认主窗口翻译开关为「已开启」
- 快捷键可能被其他软件占用，在主窗口中更换组合键
- 本工具使用 Windows 系统级热键，无需管理员权限

**Q: 翻译失败/报错？**
- **API Key 无效** → 检查 Key 是否正确、是否在百炼控制台开通了视觉模型
- **网络连接失败** → 检查网络，DashScope 需要外网访问
- **服务超时** → 稍后重试，或切换到更快的模型
- **模型返回格式异常** → 尝试更换模型（下拉选其他模型）

**Q: 覆盖层位置偏移？**
- 轻微偏移（≤5px）属正常，背景块有边距可覆盖
- 工具自动适配 125%/150% DPI 缩放

**Q: 断网能用吗？**
- 不能。本工具依赖云端 AI，需要联网。这是压缩体积（500MB+ → 46MB）所做的取舍

**Q: 框到中文怎么办？**
- 支持中英混排：英文行翻译为中文，中文行原文保留

**Q: 如何卸载？**
- 删除解压目录即可，无注册表残留
- 配置文件：`%APPDATA%\ScreenCaptureOCR\config.json`
